## 2. 기본 부품 — 미사용

| 부품 | 이유 |
| --- | --- |
| 체크박스 | 여럿 고르기는 선택 chip(`aria-pressed`)이 맡는다. 설정은 즉시 적용이라 스위치가 맞다 |
| 표준 라디오 | 고르기 알약(`role="radio"`)이 대신한다 |
| 상단 탭 | 한 화면을 여러 갈래로 나누는 곳이 없다. 기간 전환은 세그먼트 |
| 드롭다운·선택 목록 | 선택지가 적어 알약으로 펼쳐 둔다. 긴 목록은 시트 |
| 검색 필드 | D-065 ③이 세부 감정 검색을 없앴다 |
| 메뉴·팝오버 | 좁은 화면 우선이라 ⋯ 메뉴도 시트로 연다 |
| 툴팁 | 손가락 화면에서 hover에 기대지 않는다. 설명은 늘 보이는 글로 둔다 |
| 스피너 | 로딩은 스켈레톤 막대로 통일. §6.10(AI 대화, 후행 단계)이 스피너를 적었지만 그 화면이 아직 없다 — 그 화면을 만들 때 채운다 |
| 아바타 | 계정 사진 개념이 없다 |
| 전체 화면 모달 | 확인·메뉴는 모두 시트 |
| 아코디언 | 펼치기 글자 버튼 하나뿐이라 그 부품 파일에서 다룬다 |
