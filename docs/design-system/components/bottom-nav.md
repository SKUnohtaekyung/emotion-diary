# 하단 탭

기본 부품 · 틀은 [CHECKLIST.md](../CHECKLIST.md) · 상태 공통 규칙은 [DESIGN_SYSTEM §5.1](../../DESIGN_SYSTEM.md)(D-098) · 측정 기준 시안 `1bfd066`

**상태: 결정 대기 0건.** 아래에서 "값"은 `web/index.html`(마크업)·`web/css/base.css`(`.bottom-nav*`)·`web/js/main.js`를 읽고 잰 것이다. 옛 명세(§6.11)와 시안이 다른 곳은 없다 — DESIGN_SYSTEM §6.11이 이미 이 부품을 상세히 정본으로 다루고 있어 이 문서는 CHECKLIST 틀로 다시 정리한다.

## A. 쓰임

- **쓸 때**: 네 개의 최상위 화면(오늘·달력·통계·설정) 사이 이동.
- **쓰지 않을 때**: 작성 흐름·편지·온보딩·도움 안내·기록 상세·통계 친구 상세·설정 하위 화면(D-035·D-049·D-076·D-091) — 이런 화면은 `fullscreen`으로 표시돼 하단 탐색이 아예 그려지지 않고 원형 뒤로가기(‹)를 대신 쓴다.
- **나오는 곳은 밝은 화면 셋뿐**: 달력·통계·설정. 오늘 화면(어두운 숲)에는 나오지 않는다(D-076) — 그 자리는 [today.js의 `지난 기록` 알약](../../DESIGN_SYSTEM.md)이 대신한다(부품 문서 없음, 오늘 화면 전용 장식 부품).

## B. 구조

- 필수: 아이콘(24px viewBox, 25×25 렌더), 접근 가능한 이름(시각적으로는 숨긴 라벨 텍스트).
- 4개 링크가 고정 순서로 나란히 선다: 오늘 · 달력 · 통계 · 설정(D-035·D-049).
- 현재 탭 표시(`bottom-nav-indicator`, 방울)가 알약 뒤 레이어에 얹힌다.

## C. 변형

변형 없음 — 하단 탐색은 이 밝은 형 하나뿐이다(D-070·D-076, 어두운 숲 형은 D-077이 없앴다).

## D. 크기

- 전체 높이: `size.bottom-nav-height`(72) + 위 흐림 띠 24px + 안전 영역.
- 알약(rail) 최소 높이 56px, 각 링크 조작 영역 `min-width: touch-target-min`(44) × `min-height 56`(56 ≥ 44, 요구 이상).
- 현재 탭 방울(indicator) 52×52px, `radius.blob`.
- 아이콘 25×25px(뷰박스 24, 살짝 확대).

## E. 값(부품 토큰 — 4단계에서 `tokens.json`에 올린다)

| 속성 | 값 |
| --- | --- |
| 알약(rail) 면 | `service.ink`, `radius.chip`(999) |
| 현재 탭 방울 | `service.mint`, `radius.blob` |
| 비활성 아이콘 | 선(outline), 흰색(`neutral.bg`) |
| 활성 아이콘 | 면(filled), `service.ink` |
| 위 흐림 띠 | 투명 → `neutral.bg` 82% → `neutral.bg`, 24px 구간(`linear-gradient`) |

## F. 상태

| 상태 | 값 |
| --- | --- |
| 기본(비활성 탭) | 흰 선 아이콘, `aria-current` 없음 |
| 활성(현재 탭) | 면 아이콘 + `service.ink` 색, `aria-current="page"`, 방울이 이 탭 아래 위치 |
| 호버(비활성 탭만, 데스크톱) | 아이콘이 `service.mint`로 바뀐다 — `:hover:not([aria-current])` |
| 초점 | `emphasis`(2px) 링, `service.mint`, **오프셋 −4px(안쪽)** — 링과 부품 사이 간격의 공통 기준 자체가 아직 결정 대기다(§5.1 F2, CHECKLIST F2, "TASK-DS-REF 다음 라운드") — 이 부품만 새로 정하지 않는다 |
| 이동 중(`is-moving`) | 방울이 320ms 안에 옆 탭으로 옮겨가고, 도착한 탭의 색 전환은 이동 시간의 55% 뒤로 미룬다(달력 아이콘의 mint 부분이 방울과 같은 리듬으로 바뀌도록) |
| 비활성화된 탭 | 해당 없음 — 네 탭은 항상 눌린다(권한·상태로 막히는 탭이 없다) |

## G. 동작

- 링크 클릭 → 주소(`#/<탭>`) 변경 → 방울이 새 위치로 이동하며 아이콘 모양·색이 바뀐다(`main.js` render()).
- 로딩 중 다시 누르기를 막는 처리가 없다 — 라우팅은 동기적이라 막을 필요가 없다.

## H. 배치·묶음

- 화면 하단 고정(`position: sticky; bottom: 0`), 좌우 `space.3`(12) 안쪽 여백.
- 알약 위 24px 구간은 스크롤되는 본문이 그 속으로 흐려지며 사라지는 자리다(D-091 ③) — 흐림 띠는 눌리지 않고 알약만 눌린다(`pointer-events:none`은 컨테이너, `pointer-events:auto`는 알약).
- 안전 영역(`env(safe-area-inset-bottom)`)을 알약 아래 여백에 더한다.

## I. 문구

- 화면에는 라벨 텍스트가 보이지 않는다(아이콘만) — 접근 가능한 이름은 `nav-label`(시각적으로 숨김, `clip-path` 방식)이 그대로 갖고 있다: 오늘·달력·통계·설정.
- 별도 배지·숫자 문구는 없다(K 참조).

## J. 움직임

- 방울 이동: `motion.duration.slow`(320ms), 도착 시 `nav-indicator-settle` 애니메이션(눌렸다 둥글게 돌아옴).
- 색 전환(달력 아이콘의 mint 부분 등): 이동 시간의 55% 뒤로 지연.
- 움직임 줄이기: 방울 이동·눌림 애니메이션 없음(`base.css:141-142`) — 위치가 즉시 바뀐다.

## K. 접근성

- `<nav aria-label="주요 화면">`, 각 링크의 접근 가능한 이름은 시각적 라벨과 같다(오늘·달력·통계·설정) — 라벨을 숨겨도 스크린리더에는 그대로 읽힌다.
- 현재 탭은 `aria-current="page"` — 색·모양(면/선) 둘 다로 구분되어 색만으로 전달하지 않는다(§2-4).
- **알림 표시(배지)**: 해당 없음 — 지금 마크업·PRD 어디에도 배지 개념이 없다(설정의 푸시 알림도 "준비 중" 상태일 뿐 배지로 이어지지 않는다, §6.16). PRD에 없는 기능을 임의로 추가하지 않는다(AGENTS §3) — 필요해지면 그때 이 항목을 채운다.

## L. 화면 폭·기기

- 360~480: 4열 균등 분할(`grid-template-columns: repeat(4,1fr)`), 알약이 폭을 가득 채운다.
- 480보다 넓은 창에서도 하단 탐색 자체는 화면 폭 전체(콘텐츠 열 제한 없음) — 콘텐츠 열 제한(480)은 본문에만 적용된다.
- 홈 화면 앱(standalone): 아래 안전 영역을 여백에 더한다(H 참조).

## M. 장면 위에서

- 밝은 화면 셋(달력·통계·설정)에만 나온다 — 장면 색(어두운 숲·초록 언덕·편지) 위에는 올라가지 않는다(A 참조). 그래서 이 부품에는 M 항목의 "장면별 대체 값"이 없다.

## N. 하지 말 것·근거

- 색만으로 현재 탭을 표시하지 않는다 — 아이콘 모양(선/면)을 함께 바꾼다(§2-4).
- 오늘 화면·작성 흐름·편지·온보딩에 하단 탐색을 두지 않는다(D-076).
- 근거: D-035·D-049(4탭 구성, 라임→민트), D-054(ink 알약), D-070·D-076·D-077(밝은 화면 전용, 어두운 숲 유리 형 폐기), D-080 ③(활성 달력 아이콘 mint 파내기), D-091 ③(위 흐림 띠).

## O. 검수

- 전시장 상태표: 4단계에서 `design/style-guide.html`에 4탭 × (기본·활성·호버·초점) 표를 둔다.
- 하네스: 초점 링 오프셋(−4px)이 §5.1 F2 결정 이후 바뀔 수 있음을 검사 항목에 남긴다.
- 캡처: 360px에서 탭 전환 애니메이션 스냅샷(이동 중 프레임), 글자 200%(라벨이 숨겨져 있어 레이아웃 영향 없음을 확인).
