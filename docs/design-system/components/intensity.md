# 강도 선택기

기본 부품 · 틀은 [CHECKLIST.md](../CHECKLIST.md) · 상태 공통 규칙은 [DESIGN_SYSTEM §5.1](../../DESIGN_SYSTEM.md)(D-098) · 측정 기준 시안 `1bfd066`

**상태: 결정 대기 0건**(2026-09-26 D-099로 1건을 위임 판단으로 정함 — 각 항목의 '정함'을 보라). 화면 말은 '크기', 데이터 이름은 강도(intensity)다(D-065 ②). 옛 명세 §6.4가 이미 값까지 정한 부품이라 시안과 크게 어긋나지 않는다 — `web/js/components/slider.js`, `web/css/size.css`.

## A. 쓰임

- **쓸 때**: 고른 계열(대표 강도)과, 펼치면 나오는 세부 감정마다(세부 강도) 1~10 정수 하나를 정할 때.
- **쓰지 않을 때**: 값이 연속이거나 두 개 이상이면 이 부품이 아니다(이 부품은 항상 정수 1~10, 계열 강조색 하나). 펼치기 자체는 이 부품이 아니라 [펼치기(disclosure)](disclosure.md)의 몫이다.
- 이 부품은 native `<input type="range">`를 실제 컨트롤로 쓰고 그 위에 언덕·길·친구(또는 조약돌) 그림을 얹은 것이다 — 그림은 장식(`aria-hidden`), 값·키보드·스크린리더는 전부 native range가 맡는다(§6.4).

## B. 구조

- 필수: 숫자(항상 보임) + `−`/`+` 증감 버튼 + native range(투명) + 그림(언덕·길·손잡이).
- 선택: 앵커 문구(대표 강도만 있다 — 아래 E1), "따로 정함" 표(세부 강도가 대표와 달라졌을 때만).
- 영역: 위(이름·"~의 크기" + 증감 버튼·숫자) → 무대(길·손잡이) → 앵커 문구.

## C. 변형

| 변형 | 크기(`kind`) | 손잡이 | 쓰는 곳 |
| --- | --- | --- | --- |
| main(대표 강도) | 무대 64px, 손잡이(친구) 56px | 그 계열의 친구(크기는 값과 무관하게 항상 같다) | 계열 패널의 첫 슬라이더 |
| mini(세부 강도) | 무대 56px, 손잡이(조약돌) 34px | 그 계열의 조약돌(값을 따라 구른다) | 펼친 세부 감정마다 하나씩 |

- 한 계열 패널에 대표 강도 1개 + (펼쳤을 때) 그 계열에서 고른 세부 감정 수만큼의 mini가 붙는다. 화면 전체에는 고른 계열 수만큼 패널이 위에서 아래로 늘어선다(§6.4).

## D. 크기

- main 무대 높이 64, mini 무대 높이 56. 증감 버튼 44×44 원형(`step`). 숫자 칸 `min-width 4.75rem`(mini는 `3.5rem`).
- 누르는 영역: 무대 전체가 아니라 값 1~10의 자리에서 반 칸씩 바깥까지(`sz-hit`, JS가 계산) — 손가락이 스치는 것을 막기 위한 계산값(§6.4 주석, "세로 스크롤 중에 손가락이 길을 스쳐 정하지 않은 값이 '기록'되는 것을 막는다").
- 너비: 화면 폭 전체(패널 안에서 가득 채움).

## E. 값(부품 토큰 — 4단계에서 `tokens.json`에 올린다)

| 속성 | 값 |
| --- | --- |
| 채움·손잡이 테두리 | 그 계열 강조색(`category-accent`: 500, 기쁨만 700) |
| 길 | `forest.path-near`를 흰 바탕에 40% 섞은 색(`--sz-road`, 오늘 숲의 길과 같은 회색) |
| 숫자 | `2.25rem`/`800`(main), `heading`(mini) |
| 이정표 점(10개) | 채워진 구간은 숨김, 나머지는 `subtle` |
| 값 없음(고르기 전) 숫자 | "–", 손잡이는 길 들머리(자리 0)에서 대기 |

- **결정(D-099) E1 — 세부 강도(mini) 슬라이더에 앵커 문구·`aria-describedby`가 없다**: §6.4 원문은 "아래 규칙(슬라이더·스테퍼·앵커·접근성)은 대표 강도와 세부 강도에 똑같이 적용된다"고 정했지만, 실제로 앵커 문구(`.anchor-line`, 1~10 구간 설명)와 `field-error`는 `renderPanel`(대표, `slider.js:184-189`)에서만 만들어지고 세부 강도 줄(`slider.js:194-203`)에는 없다 — `describedBy`도 넘기지 않는다. 스크린리더는 `aria-valuetext`("크기 N, 10점 만점")로 값은 듣지만, "1~3 거의 스쳐 지나간 감정" 같은 구간 설명은 대표 강도에서만 듣는다. *(추천: 세부 강도에도 같은 밴드 문구를 붙인다 — §6.4가 이미 "똑같이 적용된다"고 정해 뒀고, 문구 자체(`band()` 함수)는 이미 공유되고 있어 각 mini 슬라이더에 `<p class="anchor-line">` 하나와 `aria-describedby` 연결만 추가하면 된다.)* → **정함(D-099, 위임 판단)**: 붙인다 — 세부 크기 슬라이더에도 앵커 문구(1~3·4~7·8~10)와 `aria-describedby`를 대표 크기와 똑같이 둔다. §6.4가 이미 '대표와 세부에 똑같이'라고 정했다.

## F. 상태

| 상태 | 값 |
| --- | --- |
| 기본 | 위 E, 숫자·이정표·손잡이가 그 값의 자리를 보인다. |
| 누름(증감 버튼) | `:active{transform:scale(.94)}`(`size.css:21`) — §5.1의 97%와 다른 값이지만 같은 "알약 모양이 작아진다" 계열의 표현이다(고유 수치는 유지, §5.1 통합 시 재검토). → **시안 반영(2026-09-26)**: 97%로 통일(`size.css`의 .94 삭제) |
| 초점 | native range가 `:focus-visible`이면 손잡이 둘레에 **ink 3px 링**이 뜬다(`.sz-ring`, `size.css:57-59`) — 포인터(마우스·터치)로 눌러서 얻은 초점에는 링을 띄우지 않고 키보드로 옮겨야 뜬다(`data-pointer` 속성으로 구분, `slider.js:143,155`). |
| 비활성 | 증감 버튼이 끝값(1 또는 10)에 닿으면 `aria-disabled="true"` + `opacity:.35`(`size.css:20`) — §5.1의 색-섞기 공식이 아니라 옛 투명도 방식이다(다른 부품과 같은 결함, §5.1로 바꾼다). `aria-disabled`를 써서 초점은 유지한다(맞는 선택 — §5.1 "경계가 스스로 이유를 말하는 곳은 안내 없이 비활성만 둔다"). → **시안 반영(2026-09-26)**: 면 그대로 + 기호 바탕+ink 50%, 투명도 없음 |
| 선택 | 해당 없음 — 값 자체가 상태다(고른 값이 곧 표시). |
| 로딩 | 해당 없음. |
| 상태가 겹칠 때 | 비활성(끝값)+누름: 클릭 핸들러가 `aria-disabled`를 확인해 무시한다(`slider.js:170-171`). |

## G. 동작

- **값 없음 → 값 있음**: 기본값을 미리 채우지 않는다(§6.4 ①) — 숫자는 "–", 손잡이는 길 들머리(자리 0)에서 기다린다. native range의 내부 값은 5로 초기화돼 있지만(`range.value="5"`) 화면에는 `get()`이 `null`을 돌려주는 한 "값 없음"으로만 보인다.
- **키보드**: 화살표·Home·End가 기본으로 동작한다(native range). 값이 없을 때 첫 화살표 입력은 `input` 이벤트를 안 낼 수 있어(값이 이미 5라서 안 바뀜) `keydown`에서 한 번 더 확정한다(`slider.js:144`).
- **마우스**: 누르는 즉시 그 자리 값이 되고 끄는 대로 따라간다(`press.drag=true`가 mouse는 처음부터 참).
- **터치·펜**: 탭이면 그 값으로 걸어가고(스프링), 가로로 6px 넘게 끌면 그때부터 손가락을 따라간다(움직임 없이 즉시), 세로로 움직이면 스크롤에 양보한다(`pointercancel`).
- **증감 버튼**: 눌린 채(끝값) 있지 않으면 1씩 옮기고 값을 소리 내 읽는다(`announce`).
- **세부 강도가 대표를 따라감**: 세부 강도를 따로 정하지 않은 한(own == null) `effectiveIntensity()`가 대표 값을 그대로 돌려준다 — 대표를 나중에 바꾸면 따로 정하지 않은 세부 강도만 함께 바뀐다(§6.4, "저장 계약은 바뀌지 않는다"). "대표 크기와 같게" 글자 버튼을 누르면 그 세부 강도의 `own`을 지워 다시 대표를 따르게 한다.
- **애니메이션 종류**: 스테퍼로 바꾸면 스프링(짧은 거리)이나 미끄러짐(3칸 초과, `glide`)으로 걷고 칸마다 통통 뛴다. 손가락으로 끌 때(`drag`)는 전환을 끄고 즉시 따라간다(조작감을 해치지 않기 위해, §6.4).
- **모두 정하지 않고 다음/남기기를 누르면**: 인라인 오류 대신 시트 "크기를 정하지 않은 마음이 있어요"가 열려 미정 계열을 나열한다(D-079 ①, 이 부품이 아니라 화면의 몫 — `write.js:70-82`).

## H. 배치·묶음

- 패널 안에서 위(이름·증감 버튼 줄) → 무대 → 앵커 문구 → 펼치기 글자 버튼 → (펼쳤으면) 세부 강도들 순.
- 계열 패널은 고른 순서대로 위에서 아래로(`state.draft.cats` 순서, §6.4).
- 세부 강도 줄 안에서는 이름+"따로 정함" 표 → 증감 버튼·숫자 → 무대 → "대표 크기와 같게" 글자 버튼(따로 정했을 때만) 순.

## I. 문구

- 이름 "<친구 이름>"/"<세부 감정 이름>", 접미어 "크기". 앵커 문구는 §6.4가 고정한 세 구간 문장(1~3/4~7/8~10)이다 — 화면마다 새로 쓰지 않는다.
- **증감 버튼 이름은 '증감 버튼'이라 부른다**(CHECKLIST §3 주의 — TDS의 'Stepper'는 단계 진행 표시이고 이 부품과 다른 개념이다). 접근 가능한 이름은 "<이름 또는 계열> 크기 낮추기"/"올리기"(`slider.js:75-76`, "10점 만점" 접미어는 뺀 짧은 이름을 쓴다).

## J. 움직임

- 스프링(짧은 이동, `motion.easing-spring`)·미끄러짐(3칸 초과, 최대 640ms)·손가락 따라가기(전환 없음) 세 가지(위 G). 값이 바뀔 때만 통통(`hop()`), 끌 때는 뛰지 않는다.
- 움직임 줄이기: 통통·전환이 모두 꺼지고 값은 즉시 자리를 잡는다(`reducedMotion()` 체크가 `repaint()`마다 있다).

## K. 접근성

- `<input type="range" min="1" max="10" step="1">`가 실제 컨트롤이다. `aria-label`="<이름> 크기, 10점 만점", `aria-describedby`는 앵커 문구·오류 문구 id를 잇는다(대표만 — 위 E1).
- 값이 없을 때 `aria-valuetext="아직 정하지 않음"`, 있을 때 "크기 N, 10점 만점"(`slider.js:123`).
- 그림(언덕·길·친구·조약돌)은 전부 `aria-hidden`.

## L. 화면 폭·기기

- 폭이 바뀌면(`ResizeObserver`) 풍경을 다시 계산한다 — 접힌 패널(펼치기 전)은 폭이 0이라 그리지 않다가 펼치면 다시 잰다(`slider.js:174-175`, `int-more`의 `onclick`이 `requestAnimationFrame`으로 다시 그린다).
- 360~480px에서 무대가 좌우로 늘어나며 길이 흐려지는 처리로 상자처럼 안 보인다(`mask-image`, `size.css:29-30`).

## M. 장면 위에서

- 이 부품은 흰 종이 화면(크기 화면 전체가 흰 바탕, §3.3 "적용하지 않는 화면")에만 있다 — 감정 300 면 위에는 나오지 않는다.

## N. 하지 말 것·근거

- 슬라이더만 두지 않는다(숫자+증감 버튼을 반드시 함께, §11).
- 계열 안의 색 단계(300/500/700)로 강도를 표현하지 않는다 — 채움의 *길이*만 강도를 나타낸다(§11).
- 근거: D-037(슬라이더+숫자+스테퍼로 세그먼트 대체), D-059(대표/세부 이원화), D-069 ①(길 위의 친구 스킨).

## O. 검수

- 전시장 상태표: 4단계에서 main·mini × 상태(값 없음·값 있음·끝값 비활성) 표를 `design/style-guide.html`에 둔다.
- 하네스: 4단계에서 증감 버튼의 §5.1 색-섞기 반영 여부, E1 결정 뒤 mini 앵커 문구 존재 여부를 검사에 추가한다.
- 캡처: 360px, 계열 3개 기준 패널 목록과 펼친 세부 강도 하나.
