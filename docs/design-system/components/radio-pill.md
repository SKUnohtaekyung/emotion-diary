# 고르기 알약

기본 부품 · 틀은 [CHECKLIST.md](../CHECKLIST.md) · 상태 공통 규칙은 [DESIGN_SYSTEM §5.1](../../DESIGN_SYSTEM.md)(D-098) · 측정 기준 시안 `1bfd066`

**상태: 결정 대기 0건**(2026-09-26 D-099로 2건을 위임 판단으로 정함 — 각 항목의 '정함'을 보라). 설정의 알림 시각·하루 기준 시각이 쓰는, 여럿 중 하나만 고르는 알약이다(`.st-pill`, `web/css/settings.css:52-59`).

## A. 쓰임

- **쓸 때**: 미리 정해진 여러 값 중 **딱 하나**를 고를 때(알림 시각 세 개+"다른 시각…", 하루 기준 시각 일곱 개).
- **쓰지 않을 때**: 여럿을 고르는 것 → [선택 chip](choice-chip.md). 둘 중 하나이고 폭이 좁아 나란히 둬야 할 때 → [세그먼트](segmented.md)(이 부품은 `flex-wrap`으로 줄바꿈하지만 세그먼트는 균등 폭으로 한 줄에 고정된다). 골라 놓은 값을 그냥 보여줄 때(누르는 동작 없음) → [표시용 chip](chip.md).
- 하나만 고르나 여럿 고르나(CHECKLIST §3): **하나만** 고른다(`role="radiogroup"`+`role="radio"`, `web/js/views/settings.js:122-123`).

## B. 구조

- 필수: 글자 라벨 하나. 선택: 없음(아이콘·점을 두지 않는다 — 선택 표현은 면과 굵기만으로 한다, 아래 F).
- 여러 알약을 담는 컨테이너(`.st-pills`)는 `flex-wrap`으로 줄바꿈한다.

## C. 변형

변형 없음 — 한 가지 모양뿐이다. "다른 시각…" 알약만 고른 뒤에는 그 시각 글자로 라벨이 바뀐다(`settings.js:133`, 아래 G1).

## D. 크기

- `min-height 44`, 좌우 여백 `space.4`(16), 반경 `radius.chip`(999).
- 너비: 내용 맞춤(글자 길이만큼), 줄바꿈 허용(하루 기준 시각 일곱 개는 여러 줄로 흐른다).

## G. 동작

- 누르면 즉시 그 값이 선택되고 다시 그린다(`settings.js:132,177`), 저장 버튼 없음.
- **결정(D-099) G1 — "다른 시각…" 알약의 역할 충돌**: 이 알약은 `role="radio"`인데 실제로는 **누를 때마다 항상** 기기 시간 선택기를 연다(`settings.js:121,133` — 이미 고른 뒤에도 다시 누르면 선택되는 대신 선택기가 다시 열린다). `role="radio"`는 "누르면 그 값이 선택된다"는 뜻인데 이 알약은 "누르면 값을 정하는 대화상자가 열린다"는 다른 뜻이라 스크린리더 사용자에게 혼란을 줄 수 있다. *(추천: `role="radio"`를 유지하되 접근 가능한 이름에 "다른 시각 고르기, 다이얼로그 열림" 같은 보강 문구를 더하지 않고, 대신 라벨을 "다른 시각 고르기…"처럼 동사로 바꿔 버튼성을 알린다 — role을 button으로 바꾸면 이미 고른 커스텀 값이 "선택된 라디오"가 아니게 되어 지금 고른 시각이 무엇인지 라디오 그룹 안에서 안 보이게 된다.)* → **정함(D-099, 위임 판단)**: 라디오를 유지한다. 고른 뒤에는 라벨이 고른 시각을 보인다('다른 시각 · 밤 10:30'), 다시 누르면 선택기가 열린다. 고른 값이 목록 안에서 '지금 고른 것'으로 보여야 해서다.
- 값이 바뀌면 포커스를 유지하려 애쓴다: 프리셋을 고르면 다음 렌더에서 그 알약(`.st-pill.is-custom` 또는 `aria-checked=true`)에 초점을 되돌린다(`settings.js:120,177`).
- 하위 화면 전체가 즉시 적용이라(§6.16) 이 부품에도 저장·확인 단계가 없다.

## H. 배치·묶음

- 컨테이너 안에서 왼쪽에서 오른쪽, 위에서 아래로 흐른다(`flex-wrap`). 알림 시각은 프리셋 셋 다음에 "다른 시각…"이 마지막에 온다(고정 옵션 뒤에 커스텀 옵션).
- 하루 기준 시각은 자정(0시)부터 새벽 6시까지 일곱 개가 순서대로 늘어선다.

## I. 문구

- 명사·시각 표기("오후 10시", "새벽 3시") — 버튼과 달리 동사로 끝나지 않는다(값의 이름이지 할 일이 아니다).
- 길 때는 줄바꿈 허용(컨테이너의 `flex-wrap`), 알약 하나 안에서 줄바꿈하지 않는다(짧은 시각 표기라 넘칠 일이 없다).

## J. 움직임

없음(위 F의 누름 반응 결함 참고).

## K. 접근성

- 컨테이너 `role="radiogroup"` + `aria-label`("알림 시각"·"하루 기준 시각"). 각 알약 `role="radio"` + `aria-checked`.
- 키보드: 네이티브 `<button role="radio">`라 Tab으로 각 알약에 개별 도달한다(방향키로 그룹 안을 옮기는 roving tabindex는 구현돼 있지 않다 — 표준 라디오 그룹의 화살표 이동 관행과 다르다, 미확인 — 의도적 생략인지 확인 필요).
- 대비: 고른 알약(ink 면 위 흰 글자) 중립 대비 기준(4.5:1) 이상.

## L. 화면 폭·기기

- 360~480px에서 알약이 줄바꿈해 넘치지 않는다(하루 기준 시각 일곱 개 실측 — `st-pills-day`).
- 큰 글자(200%)에서도 `flex-wrap`이 그대로 흡수한다(미확인 — 실기기 캡처 없음).

## M. 장면 위에서

해당 없음 — 고르기 알약은 설정 화면(밝은 바탕)에만 있다.

## N. 하지 말 것·근거

- 여럿을 고르는 데 쓰지 않는다(그건 선택 chip의 몫).
- 그림자를 주지 않는다.
- 근거: D-091 ④(설정 즉시 적용), D-091 ⑤(알약 결).
