# 표시용 chip

기본 부품 · 틀은 [CHECKLIST.md](../CHECKLIST.md) · 상태 공통 규칙은 [DESIGN_SYSTEM §5.1](../../DESIGN_SYSTEM.md)(D-098, 이 부품에는 적용되지 않는다 — 아래 A 참고) · 측정 기준 시안 `1bfd066`

**상태: 결정 대기 0건**(2026-09-26 D-099로 2건을 위임 판단으로 정함 — 각 항목의 '정함'을 보라). 골라 놓은 것을 **보여만 주는**(누르는 동작이 없는) pill이다. 시안에 이름이 다른 세 변형이 있다 — `.chip`(28px, `web/css/tabs.css:41`), `.sxd-chip`(36px, `web/css/stats.css:118`), `.sx-pill`(38px, `web/css/stats.css:70`). 정본 값은 옛 명세 §6.3.1이 정한 fill 100/border 300/text 900·높이 36이고, 시안에서 이 값을 그대로 구현한 것은 `.sxd-chip`뿐이다.

## A. 쓰임

- **쓸 때**: 이미 고른 감정·낱말을 다른 화면에서 다시 보여줄 때(선택 트레이 요약, 기록 카드, 통계의 낱말·범례).
- **쓰지 않을 때**: 누르면 값이 바뀌는 자리 → [선택 chip](choice-chip.md)·[고르기 알약](radio-pill.md). 이 부품은 `<button>`이 아니라 `<span>`이고 상태(§5.1)를 갖지 않는다 — 누름·초점·비활성이 없다.
- **세 변형의 경계**:
  - `.sxd-chip`(§6.3.1 그대로 — fill 100/border 300/text 900 + 8px 계열 점): 화면 전체가 **한 계열뿐**이라 색을 써도 순위로 안 읽히는 자리(친구 상세의 '<계열>에서 고른 말', `stats.js:230`).
  - `.sx-pill`(중립 회색 + 개수): 화면에 **여러 계열이 섞이는** 자리(첫 통계 화면의 '자주 머문 말', `stats.js:67`) — 감정 색으로 순위를 매기는 인상을 피하려고 일부러 중립색만 쓴다(§6.9).
  - `.chip`(28px, 중립 회색): `web/css/tabs.css:41`에 스타일만 있고 **지금 화면 어디에서도 만들어지지 않는다**(js 전체에서 `class:"chip"`·`chipline` 사용처를 찾지 못했다) — 아래 결정(D-099) C1. → **시안 반영(2026-09-26)**: `.chip`·`.chipline` CSS를 지웠다(C1)

## B. 구조

- 필수: 글자(또는 낱말) 라벨. 선택: 계열 점(`.sxd-chip`만, 8px 원) · 개수(`.sxd-chip`·`.sx-pill`, `<em>`).

INVENTORY가 측정한 "높이 28로 명세(36)와 다름"도 이 죽은 코드를 잰 것이다. *(추천: 지운다 — 정본 값(§6.3.1, 높이 36)과 다른 크기의 비슷한 이름 클래스가 CSS에만 남아 있으면 다음 작업자가 실수로 이걸 참조하기 쉽다. 요약용 작은 chip이 실제로 필요해지면 그때 `.sxd-chip`을 축소하는 변형(예: `.chip.sm`)으로 새로 만든다.)* → **정함(D-099, 위임 판단)**: 지운다 — 28px `.chip`은 시안 JS 어디서도 만들지 않는 죽은 CSS다(writer 재확인). 표시용 chip은 36px 하나로 둔다. 시안 반영 때 CSS를 지운다.

## G. 동작

- 상호작용 없음 — 데이터가 바뀌면 다시 그려질 뿐이다.
- **결정(D-099) G1 — `.sx-pill`(자주 머문 말, 첫 화면)의 개수 집계가 계열을 구분하지 않는다**: `stats-calc.js:63-71`의 `topWords()`는 낱말 텍스트만을 키로 써서 모든 계열의 같은 표기 세부 감정을 하나로 합친다. 그런데 §3.2(D-022)는 "같은 표기의 세부 감정이 카테고리마다 있을 수 있으므로 chip에는 항상 카테고리 색과 이름을 함께 보여 준다"고 정해 뒀다 — `.sx-pill`은 계열을 아예 표시하지 않으므로, 두 계열에 같은 이름의 세부 감정이 있으면 서로 다른 마음인데 개수가 하나로 합쳐져 보인다. *(추천: 집계를 `(계열, 낱말)` 쌍으로 바꾸고, 우연히 이름이 같은 두 계열의 낱말은 중립 pill 두 개로 따로 보여준다 — 색은 그대로 안 쓰되(§6.9의 "감정 색으로 순위 인상 회피" 원칙은 지킨다) 계열 이름을 괄호로 덧붙인다("허전함(슬픔)"처럼). 실제로 이름이 겹치는 세부 감정이 taxonomy에 있는지는 확인이 필요하다 — 아래 미확인 참고.)* → **정함(D-099, 위임 판단)**: 계열별로 나눠 센다. 같은 표기가 두 계열 이상에 있을 때만 이름 뒤에 계열을 붙인다(예: '허전함 · 슬픔'). D-022의 '같은 표기가 계열마다 있을 수 있다' 전제와 맞춘다(`stats-calc.js` `topWords`).

## K. 접근성

- `<span>`이라 별도 role 없이 주변 문맥(제목·caption)이 뜻을 보충한다. 개수(`<em>`)는 시각 스타일용 태그일 뿐 의미를 갖지 않는다(`font-style:normal`로 상쇄).
- 대비: `.sxd-chip`은 §9가 검사하는 chip 조합(100 위 900, 4.5:1 이상). `.sx-pill`은 중립 조합.

## L. 화면 폭·기기

- 360~480px에서 `flex-wrap`이 흡수한다. 글자 200%: 미확인.

## M. 장면 위에서

해당 없음 — 표시용 chip은 통계 화면(밝은 바탕)에만 있다.

## N. 하지 말 것·근거

- 표시용 chip에 누르는 동작을 얹지 않는다(누르게 하려면 [선택 chip](choice-chip.md)·[고르기 알약](radio-pill.md)으로 부품 자체를 바꾼다).
- `.sxd-chip`의 fill 위에 검정·회색 글자를 올리지 않는다(같은 계열 900만, §3.2).
- 근거: D-022(같은 표기 다계열), D-091 ①(친구 상세 chip 재사용), §6.9(자주 머문 말의 중립 원칙).
