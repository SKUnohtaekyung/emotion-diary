- **로그인·잠금·입구 화면(D-112, 2026-10-14)**: 로그인은 접근 열쇠로 받는 cookie 하나이고 마지막으로 쓴 날부터 30일 유지된다(틀린 열쇠는 D1 전역 잠금 — 60초에 10번 → 5분). 풀리면 '다시 들어와 주세요' 뒤 있던 화면으로 돌아간다. 앱 잠금 비밀번호(D-106)는 서버가 확인한다. 첫 버전의 입구는 접근 열쇠 화면 + 부를 이름 + 반가워요이고 시안의 소셜 로그인·동의·탈퇴는 넣지 않는다. 모든 기록 지우기는 확인 문구에 더해 잠금을 켠 경우 비밀번호를 묻고, 기록과 부를 이름·앱 잠금 설정까지 전부 지운다. 접근 열쇠는 암호 보관함에 저장할 수 있게 하고, 열쇠로 방금 들어온 직후에는 잠금 비밀번호를 묻지 않는다. 계속 쓰는 동안 로그인의 끝나는 날은 없다. 화면에서 접근 열쇠는 '열쇠', 앱 잠금은 '비밀번호'라 부른다. 설치하지 않고 Safari·PC로 들어와도 쓸 수 있다. Cloudflare Access는 첫 버전에서 쓰지 않는다(D-108). 로그아웃과 잠금을 서버에서 지키려고 서버가 세션마다 기록을 둔다(스파이크는 서명만 썼다 — 이번에 더한 설계, DATA_MODEL §3.10).
