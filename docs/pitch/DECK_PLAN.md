# 투자 소개 덱 계획서 — HON

Figma Slides로 만들 투자 소개 덱의 뼈대와 제작 계획이다. **아직 만들지 않는다**(2026-09-26 사용자 지시 — 계획서까지만). 작업 기록은 [../../tasks/TASK-DECK-01.md](../../tasks/TASK-DECK-01.md).

- 재료의 정본: [SERVICE_WHY](../SERVICE_WHY.md), [벤치마킹 분석](../research/benchmark-2026-09-analysis.md)(§3.3 강점 후보, §6 투자 자료에 쓰는 법), [경쟁 서비스 정리](../research/benchmark-2026-09-competitors.md), [BRAND_STORY](../BRAND_STORY.md), [DESIGN_SYSTEM](../DESIGN_SYSTEM.md), `design/tokens.json`, 온보딩 6장면(D-092 ②).
- 이 문서는 덱의 설계이지 제품 결정이 아니다. 덱에 쓰려고 제품 범위·결정을 바꾸지 않는다.

## 1. 사용자가 정한 것 (2026-09-26 질문 네 번)

| 항목 | 결정 |
| --- | --- |
| 대상 | 아직 정해지지 않음 — **범용 기본 덱**. 자리가 정해지면 사업 파트를 따로 만들어 끼운다 |
| 쓰는 방식 | **보내서 읽히는 덱** — 한 장에 헤드라인 한 줄 + 설명 한두 줄. 혼자 읽어도 이해되게 |
| 이야기 뼈대 | **세 가지를 모두 쓴다** — 한 사람의 하루(문 열기) → WHY(왜 중요한가) → 앱 여정(그 사람이 앱을 연다) → 시장에서 어디에 서나 → 왜 믿을 수 있나 |
| 사업 파트 | **제외** — 팀·수익 모델·투자 금액·트랙션은 이번 덱에 넣지 않는다 |
| 주인공 | **이름 없는 '나'** — 1인칭. 가상 인물이 실제 사례로 읽히거나 '청년은 이렇다'는 일반화(WHY §19.5)로 읽힐 위험을 피한다 |
| 어두운 숲 | **표지·오늘·마무리 세 곳만** — 앞뒤를 숲으로 감싸고 나머지는 앱처럼 밝은 바탕 |
| UI 표현 | **섞어서** — 앱 여정 파트는 '실제 세로 화면 + 큰 타이포', 나머지는 '슬라이드가 곧 화면'(앱 부품으로 짠다) |
| 분량 | 처음엔 **25~30장**(본편 29 + 부록 1)이었으나, 벤치마킹 막을 더하며 **35장 안팎까지 늘리기**로 바꿈 → 본편 34장 + 부록 1장 = 35장. 로고를 흰 장에 두기로 하며(아래 '숲 위의 로고') **37장**(01-b·34-b 추가) |
| 벤치마킹 | (2026-09-26 추가 질문) 처음 계획에 두 장뿐이었다는 사용자 지적 뒤 **앱 여정 뒤에 '시장' 막을 따로 세운다** — 경쟁의 축 이동, 61개와 여섯 갈래, 시장 지도, 기록을 이어 가는 세 모델, 우리가 들이지 않은 것, 기능 네 단계. '시장이 비워 둔 신뢰 장치'는 신뢰 막의 마지막 장으로 둔다 |
| 기록 깊이 | **깊이를 정체성으로** — "빠른 기분 트래커가 아니라 이름을 붙이는 기록". 부담을 줄이는 장치를 함께 보이고, 검증된 데이터가 아니라는 점을 적는다 |
| 단계 표기 | **작은 태그 + 한 장 요약** — 설계만 끝난 차별점 슬라이드 구석에 '설계 완료' 민트 테이프, 마무리 앞에 '지금 어디까지 왔나요' 한 장 |
| 표지 | **HON — 매일 남기는 마음의 흔적** (사용자 문구). HON은 **앱 이름**이다(사용자 확인 → D-058 accepted). '매일'은 **그대로 둔다**(사용자 결정) |
| 계획서 위치 | 이 파일. 커밋하지 않는다 |

## 2. 덱 한 줄과 흐름

> **HON — 매일 남기는 마음의 흔적.** AI가 답을 만들어 주는 시대에, 감정에 이름을 붙이며 나를 이해하고 내 삶의 기준을 내 쪽에서 세우게 돕는 기록.

'흔적'은 세계관과 바로 이어진다 — 조약돌은 "친구가 지나간 자리에 남긴 흔적"이다(BRAND_STORY §5). 덱은 **빈 숲(표지)에서 시작해 조약돌이 켜진 숲(마무리)으로 끝난다.** 기록이 흔적으로 남는다는 이야기를 장면 두 개로 보여 준다. 두 숲 다음에는 돌의 흰빛이 퍼진 흰 장에 **HON 로고**가 선다 — 로고의 'O'가 바로 그 가운데 돌이라, 숲의 돌이 이름 속으로 들어가는 흐름이 된다(소개 영상의 끝과 같다).

```
표지  빈 숲과 가운데 돌 하나                                    ■ 어두운 숲
01-b 흰빛이 퍼지고 HON 로고                                      □ 흰 바탕
─ 1막 나의 하루 (2~4) ─ 많이 물었고, 한 가지는 묻지 않았다       □ 민트·흰 바탕
─ 2막 WHY (5~11) ─ AI 시대 → 판단권 → 기준 → 감정이라는 신호      □ 흰 바탕·언덕·노트
─ 3막 앱 여정 (12~22) ─ 오늘 → 고르기 → 194 → 크기 → 이유 → 편지 → 흔적 → 달력·통계
                        12만 ■ 어두운 숲, 나머지는 □ 세로 화면 + 큰 타이포
─ 4막 시장 (23~28) ─ 경쟁의 축 → 61개·여섯 갈래 → 지도 → 이어 가는 이유 → 들이지 않은 것 → 네 단계
─ 5막 왜 믿을 수 있나 (29~33) ─ AI 원칙 → 근거와 한계 → 위기 → 신뢰 장치 → 지금 여기
마무리 조약돌이 켜진 숲 — "해석과 선택은 언제나 내가 해요"      ■ 어두운 숲
34-b 흰빛이 퍼지고 HON 로고                                      □ 흰 바탕
부록  출처와 해석 범위
```

막마다 숨의 길이가 다르다. 1막은 짧고 조용하게(글자 적게), 2막은 숫자 하나 또는 문장 하나, 3막은 화면이 주인공, 4막은 시장을 앱 부품(길·알약·조약돌)으로 그리고, 5막은 판단 근거를 조금 더 적는다.

4막에서 5막으로 넘어가는 다리는 28장이다 — 기능 네 단계의 '희소' 칸에 선 나의 돌이 5막의 신뢰 장치들로 이어진다. 5막 끝의 32장이 그 장치를 한 장에 모아 4막의 결론을 닫는다.

## 5. 덱 디자인 시스템 — 앱 규칙을 16:9로 옮긴다

'피피티 디자인 = 앱 디자인'이 되도록 **앱의 규칙을 그대로 쓰고, 크기만 바꾼다.** 값은 `design/tokens.json`에서 복사한다(스포이트 금지).

### 5.1 캔버스와 격자

- 1920×1080. 바깥 여백 좌우 120 · 위 96 · 아래 88. 12단 격자, 단 사이 24.
- 고정 자리: 왼쪽 아래 출처 한 줄(caption), 오른쪽 위 '설계 완료' 테이프. 쪽 번호는 오른쪽 아래 작게. 그 밖의 고정 머리·꼬리(로고 띠, 막 이름 띠)는 두지 않는다.

### 5.3 색과 면

- 기본은 흰 바탕 + 중립 text. 넓은 색 면은 역할이 있는 곳만: 숲(01·12·34), 언덕(10·19), 종이(11), 민트 옅음(02), 앱 화면 속 장면.
- 서비스 색: ink `#092328`은 알약·버튼·강조 면, mint `#62FDB4`는 ink 위나 테이프에만(흰 바탕 위 글자로 쓰지 않는다 — 대비 1.29:1).
- 감정 색은 **감정을 말할 때만** — 14·15·19의 친구·조약돌, 앱 화면 속. 막 구분, 강조, 장식에 쓰지 않는다. 아홉 계열이 한 장에 나오면 같은 크기·같은 단계로 둔다. 숫자 슬라이드(05·09)에 감정 색을 쓰지 않는다 — 통계가 감정의 좋고 나쁨으로 읽힌다.
- 24의 여섯 갈래 길과 25의 지도는 시장을 그리는 장이라 감정 색을 쓰지 않는다 — 길은 `forest` 길 회색이나 `border`, 경쟁사·범주는 중립 글자, 우리만 가운데 돌 PNG. 조약돌 모양(32)은 감정 색이 아니라 ink·흰 바탕의 유기형 면으로 그린다.
- 25의 지도: 축은 1px `border` 선, 경쟁사는 `text-muted` 작은 점 + label, 우리는 가운데 돌 PNG. 사분면 색칠·박스 금지. AI가 없는 앱(How We Feel·마음보기)은 속이 빈 점으로 따로 표시한다.

### 5.4 형태

- 그림자·박스·굵은 윤곽·다이컷 테두리·박스 속 박스·회색 위 흰 카드·제목 밑 가로선 없음(DESIGN_SYSTEM §2·§11, D-091 ⑥, D-094).
- 예외도 앱과 같다: 조약돌 PNG의 광택, 편지 종이 카드의 옅은 두 겹 그림자(D-096).
- 모서리 반경은 8·12·16·999·4와 유기형 blob만. 세로 앱 화면은 반경 16으로 자르고 폰 테두리·그림자를 두지 않는다. 흰 바탕 화면(달력·통계)은 바탕과 섞이므로 1px `border` 선 하나만 두른다.
- 묶음 나누기는 `surface-soft` 띠로(06의 토글 목록).
- 소품(테이프·쪽지·줄 노트)은 한 장에 세 곳 안팎. '설계 완료' 테이프도 소품 하나로 센다.
- 친구: 한 장의 친구는 모두 같은 크기, 박스·원 배경 없이. 64px 미만이면 이름을 함께 둔다. 친구는 말하지 않는다 — 말풍선 금지. 설이·숨이는 색이 가까워 이름을 늘 함께 둔다.

### 5.5 '설계 완료' 테이프

- 오른쪽 위, 민트 테이프(−3° 기울기) 위 ink label 글자 '설계 완료'.
- 붙는 장: 28·29·30·31·32(구현 전인 AI·위기·신뢰 장치). 33이 그 전체를 한 장에 모은다.
