# iPhone 확인 안내 — 돌아보기(달력·통계·설정 목록, 약 20분)

TASK-REFLECT-01 R-6. 관문 `reflection-core`의 `mobile-reflection`(EVAL §14). **개발용 '감정일기 개발'** 홈 화면 앱으로 본다 — 에이전트가 합성 기록(가짜 글 약 60편, 빈 날·쓰던 글이 섞임)을 넣어 둔다. 운영 앱은 쓰지 않는다.

개발용 열쇠는 이 PC의 `work/deploy/dev.PHONE-KEY.txt`를 보고 넣는다(채팅·캡처에 넣지 않는다). 부를 이름은 '시험'. 결과는 에이전트가 EVAL §4·§6 표와 PLAN에 적는다 — 한 줄씩 알려 주시고, 이상하면 캡처를 주시면 된다.

| # | 할 일 | 알려 주실 것 | 무엇을 보는가 |
| --- | --- | --- | --- |
| 1 | 아이콘 → 열쇠 → 이름 '시험' → 오늘 화면 → 아래 줄의 **달력** | 달력이 열렸는지, 아래 하단 탐색(검은 알약 + 민트 방울)이 보이는지 | 입구·하단 탐색 |
| 2 | 달력에서 **‹**로 지난달 → **›**로 이번 달 → 한 번 더 **›** | 이번 달에서 ›가 흐려져 더 넘어가지 않는지 | 미래 달 막힘 |
| 3 | 검은 조약돌 날(완료)을 누른다 → 아래 작은 편지를 옆으로 밀어 넘겨 본다 → **편지 열기** | 작은 편지가 잘리지 않고 보이는지, 넘김이 매끄러운지, 편지가 열리는지 | 작은 편지(D-100) |
| 4 | 편지 화면 위 **‹ 달력으로** → 화면 왼쪽 끝을 밀어 뒤로 | 같은 날이 고른 채로 돌아오는지 → 밀면 날짜가 닫히는지 | 돌아가기·밀어서 닫기 |
| 5 | 점선 + 연필 날(쓰던 글)을 누른다 → **이 글 지우기** → 첫 시트에서 **그만두기** | 시트가 뜨고 닫히는지(지우지는 않는다) | 쓰던 글 쪽지 |
| 6 | 하단 탐색의 **통계** → 위의 **최근 30일** | 친구들이 길을 걸어 들어와 서는지(처음 한 번), 기간을 바꿔도 다시 걷지 않는지 | 친밀도(D-064·D-080) |
| 7 | 친구 줄 하나의 **보기** → 아래로 밀며 날 칸을 몇 개 눌러 본다 | 언덕 위 친구가 잘리지 않는지, 고른 날의 편지 미리보기가 바뀌는지, 옆으로 밀리는 곳이 없는지 | 친구 상세(D-101~D-103) |
| 8 | 미리보기의 **편지 열기** → **‹ 통계로** | 같은 친구·같은 기간으로 돌아오는지 | 돌아가기 |
| 9 | 하단 탐색의 **설정** → **앱 잠금** → 뒤로 | 설정 목록이 보이고 오가는지, 오른쪽 아래 **상태** 버튼이 탐색 위에 떠서 '설정' 칸을 가리지 않는지 | 설정 목록(D-129) |
| 10 | 아이폰 **설정 → 손쉬운 사용 → 디스플레이 및 텍스트 크기 → 더 큰 텍스트**를 크게 → 앱으로 돌아와 달력·통계를 본다(끝나면 되돌린다) | 앱 글자가 커지는지, 겹치거나 잘리는 곳이 있는지 | 큰 글자(MAP R7 — 홈 화면 앱에 닿는지 모른다) |
| 11 | 아이폰 **손쉬운 사용 → 동작 → 동작 줄이기**를 켜고 → 통계를 다시 연다(끝나면 끈다) | 친구가 걷지 않고 바로 서 있는지 | 움직임 줄이기(R6) |
| 12 | 앱을 **완전히 닫고** 다시 연다 → 하단 탐색으로 달력 | 다시 열쇠를 묻지 않는지 | S-02 |

끝나면 에이전트가 개발용 데이터를 비운다(합성 기록·로그인).
