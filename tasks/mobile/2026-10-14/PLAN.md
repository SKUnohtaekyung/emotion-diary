# 2026-10-14 TASK-MOBILE T2 계획 — 정본 동기화

요청 원문과 답은 [REQUESTS.md](REQUESTS.md). **이 문서가 이 작업의 유일한 진행 기록이다.** 한 항목을 끝낼 때마다 체크하고 그 줄에 결과를 적는다. 문서 하나가 끝나면 `node scripts/verify.mjs --mode quick`을 돌리고 다음으로 간다. 커밋·푸시는 사용자 지시 때만.

이어서 하는 사람(요약된 대화에서 돌아온 에이전트 포함)은 ① 아래 '체크리스트'에서 첫 번째 빈 칸을 찾고 ② '사실표'의 값만 옮겨 적으며 ③ '에이전트가 정한 것'과 REQUESTS의 '사용자가 고른 것'을 섞지 않는다.

## 작업 규칙

- 문서는 대부분 CRLF다. 기존 파일은 Edit 도구로 한 곳씩 고치고 스크립트로 여러 파일을 한꺼번에 바꾸지 않는다. 고친 뒤 LF 수 = CRLF 수인지 바이트로 센다(`grep -c`는 믿지 않는다 — 2026-10-14 여러 파일에 0을 냈다).
- **Git Bash의 `sed -i`는 CRLF를 LF로 바꾼다**(2026-10-14 실제로 네 파일이 바뀌어 바이트로 세고 되돌렸다). 기존 파일은 Edit 도구나, CRLF를 벗겼다 다시 씌우는 node 스크립트로만 고친다.
- "확인됨"에는 어디서 확인했는지(S 번호·날짜·문서 URL)를 같이 적는다. 실측과 규격 판단과 공식 문서 확인을 구분한다.
- 사용자 결정으로 적는 것은 REQUESTS의 '사용자가 고른 것' 칸뿐이다.
- 앱 코드와 `web/`은 건드리지 않는다. 명세가 시안과 달라지는 곳에는 "시안은 그대로이고 화면을 옮길 때 맞춘다"를 적는다.

## 공식 문서 확인 (조사 담당 2026-10-14, 요약과 출처만)

- Cloudflare: Worker 하나가 정적 자산과 스크립트를 함께 낸다. `run_worker_first`는 불리언 또는 경로 패턴 배열. 정적 자산 요청은 무료·무제한이고 Worker를 먼저 타는 경로만 요청 한도에 잡힌다(한도 초과 시 429). 기본 캐시는 `public, max-age=0, must-revalidate` + ETag. "Start new projects with Workers" 문장이 지금도 있다. — developers.cloudflare.com/workers/static-assets/binding/ · …/billing-and-limitations/ · …/headers/ · developers.cloudflare.com/pages/ (**사실**)
- WebKit: 7일 상한은 `document.cookie`로 만든 cookie와 스크립트 저장소(localStorage·sessionStorage 등)에 적용된다. 서버가 심은 HttpOnly cookie가 비대상이라는 문장은 공식 문서에 **없다**(비대상이라는 것은 추론). 홈 화면 웹앱은 그 7일 상한에서 제외된다(**사실**). — webkit.org/blog/8613/ · webkit.org/tracking-prevention/ · webkit.org/blog/10218/
- cookie 최대 수명 400일 상한: 원문을 열지 못했다(**미확인**). 30일 연장식은 이 범위 안이다.
- 홈 화면 웹앱은 브라우저와 cookie·저장 공간이 따로다(WWDC23 10120, **사실**). iOS에서 Safari cookie가 복사된다는 공식 서술은 없다.
- 홈 화면 웹앱에서 암호 자동 입력이 된다는 공식 근거: **없음(미확인)** — 실기기 확인 필요.
- iOS 26: 홈 화면에 추가한 사이트는 기본으로 웹 앱으로 열리고 추가할 때 끌 수 있다(끄면 Safari 북마크처럼 열린다). manifest는 필수가 아니다(**사실**). — webkit.org/blog/17333/
- 파일 공유: Safari 15부터, 사용자 조작(버튼 누름) 안에서만. 홈 화면 웹앱에서 된다는 공식 문장은 없다 — **우리 실측(S-05)이 근거**.
- scope 밖 링크는 앱 안의 Safari 창(Safari View Controller)으로 열린다(WWDC23, **사실**, 실측 S-09와 일치). 가장자리 밀어 뒤로 가기는 공식 서술 없음 — **실측(S-08)이 근거**.
