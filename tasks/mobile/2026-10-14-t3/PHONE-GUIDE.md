# iPhone 확인 안내 — 앱 뼈대(개발용 건물)

TASK-MOBILE T3 6단계. 이 안내는 휴대폰을 직접 만지시는 분을 위한 것이다. 결과는 에이전트가 [PLAN.md](PLAN.md) 6-3 표에 적는다.

## 먼저 알아 둘 것

- 이 앱은 **개발용 건물**이다. 홈 화면 이름은 **'감정일기 개발'**이다. 실제 일기나 실제 이름은 넣지 않는다 — 이름은 '시험'처럼 아무 말이나 쓴다.
- **주소**는 채팅으로 드린다(공개 저장소에는 적지 않는다).
- **열쇠**(12글자)는 이 PC에서 `work/deploy/dev.PHONE-KEY.txt` 파일을 열어 보고 휴대폰에 직접 입력한다. 채팅·캡처에 열쇠를 넣지 않는다. 대문자·소문자를 가린다.
- 화면 오른쪽 아래 **'상태'** 버튼은 개발용에만 있다. 누르면 글자로 된 상태표가 펼쳐진다 — 캡처를 부탁드릴 때 이것을 펼친 채 찍어 주시면 된다. 상태표에는 적은 글·열쇠·이름이 나오지 않는다.
- 캡처는 이 채팅에 붙여 주시면 된다. 홈 화면처럼 다른 앱이 보이는 캡처는 보내지 않아도 된다(보관하지 않는다).
- 단계마다 '알려 주실 것'만 짧게 답해 주시면 된다. 안 되거나 이상하면 그 자리에서 멈추고 알려 주시면 된다.

## 1회차 — 설치와 로그인 (8단계)

| # | 할 일 | 알려 주실 것 |
| --- | --- | --- |
| 1-1 | iPhone **Safari**로 채팅의 주소를 연다 | 열쇠 화면이 뜨는지, 아래에 '홈 화면에 추가해 앱처럼 열 수 있어요 ›' 줄이 있는지 |
| 1-2 | Safari 아래쪽 **공유** 버튼 → **홈 화면에 추가**. '웹 앱으로 열기'는 **켠 채로** 추가한다 | 추가 화면에 보인 이름이 '감정일기 개발'이었는지 |
| 1-3 | 홈 화면의 **'감정일기 개발'** 아이콘으로 연다 | 주소창이 없는지 |
| 1-4 | 오른쪽 아래 **'상태'** → 펼친 채 **캡처** → 다시 눌러 접는다 | 캡처 |
| 1-5 | PC에서 열쇠 파일을 보고 열쇠 칸에 입력 → **들어가기** | 암호를 저장하겠느냐는 창이 떴는지(떴으면 **저장**을 누른다) |
| 1-6 | 부를 이름에 '시험' → **시작하기** → 반가워요에서 **오늘 시작하기**(잠금은 아직 켜지 않는다) | 오늘 화면이 떴는지 |
| 1-7 | 오늘 화면의 **연습 칸**을 눌러 아무 글이나 몇 글자 적는다(자판이 떠 있는 채로) → **캡처** → '상태'를 펼쳐 한 장 더 **캡처** | 자판이 떠 있을 때 화면 아래 **'연습 버튼'**이 보이는지·가려지는지(캡처 두 장) |
| 1-8 | 앱을 **완전히 닫는다**(아래에서 위로 밀어 앱 전환 화면 → 이 앱 카드를 위로 밀어 끔) → 바로 아이콘으로 다시 연다 | 열쇠를 다시 묻지 않고 오늘 화면이 뜨는지 |

## 2회차 — 앱 전환 화면 가림과 잠금 (7단계, 15분쯤)

| # | 할 일 | 알려 주실 것 |
| --- | --- | --- |
| 2-1 | (잠금 꺼진 채) 오늘 화면에서 아래에서 위로 살짝 밀고 멈춰 **앱 전환 화면**을 띄운다 → 이 앱 카드를 **캡처** | 카드가 짙은 남색으로 덮였는지, 오늘 화면 글이 보이는지 |
| 2-2 | 앱으로 돌아와 **앱 잠금** → 스위치 켜기 → 비밀번호 네 자리 두 번(아무 숫자) → 오늘 | '잠금을 걸었어요'가 떴는지 |
| 2-3 | 2-1처럼 앱 전환 화면을 띄워 카드를 **캡처** | 카드가 덮였는지 |
| 2-4 | 다른 앱으로 가서 **4분** 있다가 돌아온다 | 잠금 화면 없이 그대로인지 |
| 2-5 | 다른 앱으로 가서 **6분** 있다가 돌아온다 → 비밀번호로 푼다 | 비밀번호 화면이 떴는지 |
| 2-6 | 앱을 **완전히 닫고** 1분 안에 아이콘으로 다시 연다 → 비밀번호 화면이면 **'상태'를 펼쳐 캡처** → 푼다 | 비밀번호를 물었는지 + 캡처 |
| 2-7 | '상태' 펼침 → **바깥 링크 열기(T-02)** → 열린 창에서 **완료**(또는 왼쪽 위 닫기)로 돌아온다 → '상태' 펼쳐 **캡처** | 돌아왔을 때 화면이 처음부터 다시 열렸는지(불러오는 중이 잠깐 보였는지), 비밀번호를 물었는지 + 캡처 |

## 3회차 — 화면 이동·새 버전·로그인 풀림 (5단계)

| # | 할 일 | 알려 주실 것 |
| --- | --- | --- |
| 3-1 | 오늘 → **앱 잠금** → 화면 **왼쪽 끝**에서 오른쪽으로 민다 | 오늘 화면으로 돌아왔는지 |
| 3-2 | 오늘 → **시트 열기** → 시트가 열린 채 화면 왼쪽 끝에서 민다 | 시트만 닫히고 오늘 화면에 그대로인지 |
| 3-3 | 연습 칸에 글을 적어 둔다 → 채팅으로 **"새 버전 올려 주세요"** → 제가 "올렸어요" 하면 다른 앱에 잠깐 갔다 돌아온다 | 맨 위에 '새 버전이 있어요' 띠가 떴는지, 연습 칸의 글이 그대로인지(저절로 새로 고쳐지지 않았는지). 그다음 띠의 **새로 고치기**를 누른다 |
| 3-4 | 오늘 화면에서 채팅으로 **"로그인 풀어 주세요"** → 제가 "풀었어요" 하면 **앱 잠금** 버튼을 누른다 | '다시 들어와 주세요' 열쇠 화면이 떴는지(연습 칸에 글이 있었다면 '다시 들어와야 해요' 시트가 먼저) |
| 3-5 | 열쇠를 넣는다 — 열쇠 칸을 누르면 저장해 둔 열쇠를 **자동으로 채우자는 제안**이 뜨는지 본다(뜨면 쓴다) → 들어가기 | 자동 입력 제안이 떴는지, 들어간 뒤 '앱 잠금' 화면(있던 자리)으로 돌아왔는지 |

## 4회차 — 시간이 지나야 보는 것(할 수 있을 때)

| # | 할 일 | 알려 주실 것 |
| --- | --- | --- |
| 4-1 | **12시간 넘게 지나서**(다음 날 아침 등) 아이콘으로 연다 | 열쇠를 다시 묻지 않는지(잠금을 켰으면 비밀번호만 묻는다) |
| 4-2 | 연습 칸에 글을 적고 다른 앱에 **5분**, 한 번 더 **30분** 있다가 돌아온다 | 글이 그대로인지 |
| 4-3 | Safari에서 주소를 열어 **'웹 앱으로 열기'를 끈 채** 홈 화면에 추가 → 그 아이콘으로 연다 | Safari로 열리는지, 열쇠로 들어가 쓸 수 있는지 |
| 4-4 | '감정일기 개발' 아이콘을 **지웠다가** 다시 추가해 연다 | 열쇠를 다시 묻는지 |
