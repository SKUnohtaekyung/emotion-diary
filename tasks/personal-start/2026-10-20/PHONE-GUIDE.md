## 1부 — 개발용 '감정일기 개발'에서 자판 배치 고르기(약 8분, 가짜 문장)

개발용은 검사 끝에 로그인을 비웠다 — 열쇠는 이 PC의 `work/deploy/dev.PHONE-KEY.txt`를 보고 넣고, 부를 이름은 '시험'.

| # | 할 일 | 알려 주실 것 |
| --- | --- | --- |
| 1 | 아이콘 → 열쇠 → 이름 '시험' → 오늘 화면 → 오른쪽 아래 **상태** → 위쪽 버튼 줄에서 **A 그대로**를 누르고 **상태**를 다시 눌러 접는다 | — |
| 2 | **오늘의 마음 남기기**(4·5에서는 **이어서 써요**) → 글 칸을 눌러 자판을 띄우고 한 줄 적는다 → 자판이 떠 있는 채로 **캡처** → 화면을 위로 밀어 **다음**이 보이는지 본다 | 위쪽 ✕·'1 / 7'이 시계·배터리와 겹치는지, **다음**이 보이고 눌리는지 |
| 3 | 자판을 내린다 → **상태**를 펼쳐 맨 위 '자판 · …' 기록이 보이게 **캡처**(두세 장이어도 된다) | 화면 아래 빈 띠가 있는지 |
| 4 | 위 **✕**(그만두기)로 오늘 화면에 돌아와 **상태** → **B 최소 높이 없음** → 2·3을 똑같이 | 같은 둘 + 캡처 |
| 5 | 같은 방법으로 **C 안쪽 스크롤** → 2·3 | 같은 둘 + 캡처 |

어느 배치가 '겹침 없음 + 다음이 닿음'인지 에이전트가 기록 숫자와 함께 판정한다. 셋 다 겹치면 그대로 알려 주시면 된다(관문은 그대로 진행한다).
