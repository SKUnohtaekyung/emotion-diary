로딩 화면 — 조약돌 모양과 기다림 표시

B안(아이콘에서 이어짐)을 다듬는다. 원 대신 오늘 화면 돌의 실루엣을 딴 평면 조약돌로, 그리고 오래 걸릴 때만 움직이는 표시를 단다.

  1. 0.3초 안에 준비되면 로딩 화면을 아예 보이지 않는다
  2. 0.3~2초: 조약돌만 가만히(1초 안팎의 짧은 기다림에 반복 움직임은 오히려 거슬린다 — NN/g)
  3. 2~10초: 움직이는 표시 하나(아래 ②에서 고른다)
  4. 10초가 넘으면: '연결이 느린 것 같아요 · 다시 시도'
  5. 준비되면 언제든 조약돌이 오늘 화면의 돌 자리로 내려앉으며 넘어간다(보였다면 최소 0.6초)
